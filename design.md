# Design System & UI/UX Specification

## Design Aesthetic & Theme
* **Visual Identity:** Sleek modern SaaS interface featuring high-trust Indigo/Violet accents, glassmorphic cards, rounded status badges, and subtle borders.
* **Typography:** Primary font `Inter` or `Plus Jakarta Sans`; Monospace font `JetBrains Mono` for code components.
* **Color Palette:**
  * **Primary Brand:** Electric Indigo (`#5856D6`) / Violet (`#6C5CE7`)
  * **Success Accent:** Emerald Green (`#10B981`)
  * **Warning / Alert:** Amber (`#F59E0B`)
  * **Backgrounds:** Slate Black (`#0F172A`) dark hero & Off-White (`#F8FAFC`) light dashboard surfaces.
