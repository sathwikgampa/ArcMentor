# DSA Interview Question Bank

## Problem Categories
Questions are organized by difficulty and topic. Each problem includes:
- Problem statement & constraints
- Progressive hint schedule (3 hints, unlocked at 5-minute intervals)
- Test cases (visible + hidden)
- Reference solution with time/space complexity analysis

---

## Array & Hashing

### Easy
1. **Two Sum** — Find indices of two numbers that add up to target.
2. **Contains Duplicate** — Check if array has duplicate values.
3. **Valid Anagram** — Determine if two strings are anagrams.

### Medium
1. **Group Anagrams** — Group strings that are anagrams of each other.
2. **Top K Frequent Elements** — Return k most frequent elements.
3. **Product of Array Except Self** — Calculate products without division.

### Hard
1. **Longest Consecutive Sequence** — Find length of longest consecutive element sequence.

---

## Linked Lists

### Easy
1. **Reverse Linked List** — Reverse a singly linked list.
2. **Merge Two Sorted Lists** — Merge two sorted linked lists.

### Medium
1. **Reorder List** — Reorder L0→Ln→L1→Ln-1→...
2. **Remove Nth Node From End** — Remove the nth node from end.
3. **Linked List Cycle** — Detect cycle in linked list.

### Hard
1. **Merge K Sorted Lists** — Merge k sorted linked lists.

---

## Trees & Graphs

### Easy
1. **Invert Binary Tree** — Mirror a binary tree.
2. **Maximum Depth of Binary Tree** — Find max depth.

### Medium
1. **Binary Tree Level Order Traversal** — BFS level-by-level output.
2. **Validate Binary Search Tree** — Verify BST property.
3. **Number of Islands** — Count connected components in grid.

### Hard
1. **Serialize and Deserialize Binary Tree** — Encode/decode tree structure.

---

## Dynamic Programming

### Easy
1. **Climbing Stairs** — Count ways to reach top.

### Medium
1. **Coin Change** — Minimum coins for amount.
2. **Longest Increasing Subsequence** — Find LIS length.
3. **Word Break** — Can string be segmented into dictionary words?

### Hard
1. **Edit Distance** — Minimum operations to convert one string to another.
